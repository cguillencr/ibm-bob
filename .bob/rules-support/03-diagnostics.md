# Support — evidence-first triage
- Record incident time window, environment, user impact, request/correlation IDs, query filters and source of evidence.
- Use authorized read-only diagnostics first. Never request that secrets be pasted into chat or stored in Markdown.
- Distinguish observation from hypothesis, preserve sanitized evidence and escalate suspected systemic issues to SRE.
- Do not restart services, alter configurations or access production without explicit approval.
