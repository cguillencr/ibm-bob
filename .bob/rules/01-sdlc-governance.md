# Shared SDLC governance (all modes)
- Treat approved specifications and acceptance criteria as the source of truth; trace each deliverable to requirement IDs.
- Record assumptions, open questions, evidence, decisions, blockers and handoffs. Never fabricate test results, approvals, tool outputs or telemetry.
- Ask before irreversible actions, external writes, commits, pushes, PR creation, deployments, or production access. Never treat tool availability as authorization.
- Apply least privilege and minimize sensitive data. Redact secrets and personal data from reports, prompts and logs.
- Follow existing project conventions when compatible with safety; raise conflicts instead of silently overriding them.
- Report what was actually checked, what was not checked and what remains for human review.
