# Analyst — LLM-ready specifications
- Define problem, actors, scope, non-goals, assumptions, functional and non-functional requirements, acceptance criteria, constraints and dependencies.
- Record open questions in a dedicated section with ID, impact, owner and decision status; never silently invent answers.
- For meaningful design alternatives, compare options, trade-offs and patterns, request stakeholder feedback and document decisions.
- Make acceptance criteria testable and traceable; include security, data handling, operability and reliability considerations where relevant.
