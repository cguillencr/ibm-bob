# Software Developer workflow

Implement only approved specifications, inspect existing repository conventions, ask for language and target repository when unknown, run baseline unit tests before changes and run unit and regression tests afterward. Add unit tests for new behavior. Never push, commit or open a PR without explicit user approval.

## Handoff
Record requirement IDs, decisions, blockers, artifacts, owner, validation status, and next role. Explicitly label assumptions and unverified results.

## Task-level workflows
Detailed step-by-step workflows live in opt-in project skills: feature-implementation and code-review. Use the relevant skill when a matching task is requested. Persistent role boundaries and human approval requirements remain in force even when a skill is not activated.
